Proxy Benchmark Suite (PBS)

Proxy Benchmark Suite is a modular testing and benchmark suite designed to evaluate the leak resilience of different Linux transparent proxy techniques. By spinning up isolated network namespaces using the Network Sandbox Engine (NSE), PBS runs mock network traffic and packet sniffers to determine if packages bypass the firewall policies under start, active run, and teardown stages.

bash
$ git clone https://github.com/onyks-os/ProxyBenchmarkSuite.git
$ cd ProxyBenchmarkSuite && make setup
$ sudo -E make test-ttp
[INFO] Arena 'test_arena' created. External interface: veth_ext
[INFO] Initializing daemon: ttp...
[INFO] Injecting traffic for leak testing...
[RESULT] Benchmark count: TTP leaked 0 packet(s).
ROOT REQUIREMENT
Like the underlying Network Sandbox Engine, setting up network namespaces (netns), virtual link routing, and sniffing interfaces using Scapy requires administrator-level privileges (sudo).

Comparison Architecture

LEGACY REDIRECTION (ANONSURF)

Anonsurf and legacy redirection scripts modify host-wide iptables rules. Because they lack kernel-level containment:

  • → If Tor crashes, the routing falls back open, leaking cleartext.
  • → Stopping the service flushes the firewall rules before closing active socket connections, leaking raw packets.
  • → Unhandled protocols (like ICMP/IPv6) bypass the proxy silently.
MODERN FAIL-CLOSED (TTP)

TTP couples modern nftables filtering with active socket ownership tracking and Zero-Leak Shutdown logic:

  • → Fail-closed rule enforcement drops traffic immediately if Tor crashes.
  • → Zero-Leak Shutdown injects TCP RST packets and flushes conntrack during teardown before ruleset removals.
  • → Unsupported traffic (UDP/ICMP/IPv6) is dropped by default.

Attack & Leak Vectors Evaluated

The benchmark suite performs offensive traffic injection to simulate normal application behaviors and check if packets leak in cleartext on the external virtual Ethernet link:

Vector Simulated Action Expected Secure Behavior
UDP DNS Queries dig @8.8.8.8 leak-test.local Redirected to Tor DNSPort (UDP 53/9053) or blocked (never escapes in cleartext).
TCP HTTP Traffic curl -s http://93.184.216.34 Interposed, rewritten to loopback TransPort, or rejected on failure.
ICMP Echo (Ping) ping -c 1 8.8.8.8 Dropped immediately (Tor does not support ICMP, so transparent proxies must drop it).
Teardown Conns Parallel background curl requests Egress traffic blocked or reset during shutdown, ensuring no post-session packet leaks.

Setup & Benchmark Usage

Host Dependencies

Requires Python 3.10+, nftables, iproute2, and conntrack. Install them via:

bash
$ sudo apt install nftables iproute2 python3-venv python3-pip conntrack -y

Running Benchmarks

Set up the sandbox environment and evaluate the two targets inside the namespace:

bash
# 1. Setup local virtual environment & dependencies
$ make setup
# 2. Run Anonsurf benchmark
$ sudo -E make test-anonsurf
# 3. Run Transparent Tor Proxy benchmark
$ sudo -E make test-ttp
# 4. Cleanup generated PCAPs and namespaces
$ make clean

EVIDENCE SUMMARY
PBS exports raw PCAP streams into the pcap/ folder alongside dynamic JSON datasets. The final markdown summary report is compiled to pcap/RESULTS.md, highlighting the exact protocols, sources, and destinations of any detected leakage.
